# دعوة فرح إلكترونية

مشروع منفصل تماماً عن سيستم المحل — ملف `index.html` + `door.webp` (صورة الباب) + `music.mp3`.

## الشكل
- مدخل بصورة حقيقية (`door.webp`): باب عاجي ودهب تحت قوس ورد وفوانيس — الضلفتين متقصوصين من الصورة نفسها، فلما الضيف يضغط بيتفتحوا لجوه والنور يطلع والكاميرا تدخل
- بعدها 6 صفحات زي الستوري (خطوط فوق)، وكل ضغطة بتقلب الصفحة زي الكتاب:
  1. الأسماء والتاريخ  2. العدّاد  3. الآية  4. الشكر  5. الميعاد والمكان  6. الختام
- الصفحات بتتقلب لوحدها كل 4 ثواني (الآية والشكر 7 ثواني) وبتقف عند آخر صفحة
- الضغط شمال/وسط الشاشة = الصفحة الجاية، الثلث اليمين = اللي قبلها، أو السحب بالصباع (زي كتاب عربي)

## تعديل البيانات
افتح `index.html` وابحث عن `const CONFIG = {` — غيّر الأسماء والتاريخ والقاعة من هناك بس.

## الموسيقى
- `music.mp3` — River Flows in You (Yiruma) — ملف من صاحب الدعوة، والأغنية حقوقها محفوظة لـ Yiruma (اختيار صاحب الدعوة وعلى مسؤوليته)
- بتحاول تشتغل أول ما اللينك يتفتح؛ لو المتصفح منعها (أغلب الموبايلات بتمنع) بتشتغل مع أول لمسة
- لتغييرها: حط ملفك جنب index.html واكتب اسمه في `music` جوه CONFIG
